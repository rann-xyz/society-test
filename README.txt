SOCIETY — GALAXY / 3D UPGRADE
================================

This is a complete standalone upgraded version of the Society website.

Main changes:
- Society PNG logo is used in the top-left navigation and throughout the site.
- Floating 3D "SOCIETY" and "S" elements are generated with Three.js.
- Space/galaxy background: stars, dust, nebula, planet, orbit rings and floating geometry.
- Direct social links:
  X: https://x.com/SocietyFolks
  Discord: https://discord.gg/societyid
  Instagram: https://www.instagram.com/societyfolks?igsh=MWp3aHVjeGEycnl2
- Responsive mobile navigation.
- Five complete pages: Home, About, Services, FAQ, Join.
- No npm install is required; Three.js is loaded through CDN/importmap.

RUN:
1. Extract the ZIP.
2. Open a terminal inside the folder.
3. Run:
   python -m http.server 8000
4. Open:
   http://localhost:8000
